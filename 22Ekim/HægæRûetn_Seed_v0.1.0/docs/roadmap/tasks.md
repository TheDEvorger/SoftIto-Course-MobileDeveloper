# Canonical roadmap

- [ ] **TASK-001 / Bootstrap & verify:** Run Flutter scaffolding, pub get, format, analyze, tests, smoke test on Chrome or emulator. Fix real errors; report actual status.
- [ ] **TASK-002 / Resilient local data:** Add versioned schema, atomic backups/export/import, daily rollover even if app stays open past midnight, recovery and offline storage tests. Do not ever overwrite a malformed saved payload silently.
- [ ] **TASK-003 / Pact engine:** Clarify streak-vs-total days. Add deadline, pause, immutable past achievements, cancellation, anti-double-award tests, and validation for archived habits.
- [ ] **TASK-004 / Rank & XP balance:** Simulate 1/7/30/90/365 days, calibrate slow rank climb / fast but fair reputation loss. Add user-selected difficulties and better rest scheduling.
- [ ] **TASK-005 / 24 badges:** Implement all locally-verifiable badge rules. Label community-only badges gated until real server exists. Prevent self-awarded fake support points.
- [ ] **TASK-006 / Original art:** Illustrate six ORIGINAL age backgrounds, 24 ORIGINAL badge emblems, 6 UI icon families; no borrowed/licensed-unknown art, preserve source and export sizes, light/dark contrast.
- [ ] **TASK-007 / Micro-interactions:** Herald appears, rotates, snoozes; page transitions, motion-reduced confetti, earned achievements and larger rank animations.
- [ ] **TASK-008 / Analytics:** Weekly/monthly calendar, goal consistency and trends, rest-day-aware streaks, accessible chart labels and generated kronik summaries.
- [ ] **TASK-009 / Optional real AI:** Consent-driven provider adapter, local-only default, system prompt preview, safe per-user API key storage (never hardcode), cost notice, fallback.
- [ ] **TASK-010 / Real community:** Auth only when user opts in, content moderation, privacy, anti-abuse scoring, reporting/blocking, data deletion and backend integration.
- [ ] **TASK-011 / Notifications:** Explicit OS permission, reminders only at user-approved times, quiet hours, limit frequency, disable at will.
- [ ] **TASK-012 / Final polish:** Accessibility, localization, app icons, tests across platforms, privacy/legal copy, release build instructions.

All numbers above are sequence IDs, NOT a claim that tasks were completed. No forced account creation, no dark and oppressive visuals, no unverified networked features.
