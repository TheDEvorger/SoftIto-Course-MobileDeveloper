# VenaFlow | Antigravity Hazırlık Paketi

**İçindekiler:**
- `Project.md`: Proje kapsamı, estetik yön, teknoloji sınırları, mimari ve kabul kriterleri.
- `.agents/skills/SKILL.md`: Modüler Flutter feature geliştirme standardı.
- `ANTIGRAVITY_BASLANGIC_PROMPT.md`: Antigravity sohbetine doğrudan yapıştırılacak ilk talimat.

**Nasıl kullanılır?** Bu klasörü Antigravity çalışma alanı olarak aç veya içindekileri mevcut Flutter projenin köküne ekle. `ANTIGRAVITY_BASLANGIC_PROMPT.md` içeriğini Antigravity'ye mesaj olarak gönder. `Project.md` ve `SKILL.md` dosyalarının okunmasını iste.

**Not:** Bu paket kaynak kod / hazır uygulama değil; geliştirme yönergeleri setidir. Sahte sağlık verileri kullanır ve gerçek klinik sistem olarak tasarlanmamıştır.
