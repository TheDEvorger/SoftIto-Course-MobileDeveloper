# Flutter görsel varlıkları

`scenes/` içindeki 10 WebP dosyası uygulamada doğrudan kullanılır. Ustalar `../../design/source_art/` altındaki ayrı PNG'lerdir. `asset_manifest.json` dosyasındaki eşleşme ve SHA-256 doğrulamasını koruyun. `flutter pubspec.yaml` altında `assets/illustrations/scenes/` kayıtlıdır.

PNG → WebP kopyalarını Flutter uygulamasında boyutu azaltmak için yaptık. PNG'ler burada gereksizse bile tasarım arşivinden SİLMEYİN.
