# Docs and tasks
- 250 lines per user-authored file; aim under 120.

- A Task has dependency, scope, non-goals, acceptance, verification.
- Do not put architectural decisions in chat only: add a short ADR.
- Keep task status accurate; log failing tests and blockers.
