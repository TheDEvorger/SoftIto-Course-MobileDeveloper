# Security checks
1. Identify assets, actors, trust boundaries and attack surface.
2. Public profile must not imply public private venture data.
3. Server-side access enforcement for every shared object.
4. Rate limits, reporting, abuse prevention before public messaging.
5. No secret in app binary or repository; threat-model backup/encryption.
6. Document threats and mitigations, test access denial cases.
