# Definition of done
- Task acceptance criteria each linked to verifiable evidence.
- No newly introduced analyzer errors; tests pass on intended platform.
- Source files <=250 lines; generated files inventory noted separately.
- Secrets absent, scope boundaries intact, migrations reviewed.
- README/docs updated if commands or user behavior changes.
- Active task moved to done; index/handoff reflect reality.
- One short status block: changed / verified / blocked / next.
