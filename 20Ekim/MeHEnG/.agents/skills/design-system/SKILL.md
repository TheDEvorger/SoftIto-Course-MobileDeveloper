# UI craft
Read `docs/design/tokens.md` and `docs/design/screens.md`.
Use named semantic colors, no ad hoc random palette.
Use minimum 44x44 tap targets where practical.
Verify contrast, semantics and keyboard focus.
Test widths: 360, 600, 900, 1440.
Use content hierarchy, not excessive cards or gradients.
