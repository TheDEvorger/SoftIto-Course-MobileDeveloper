# Task decomposition
1. Define a user-visible outcome, non-goals and preconditions.
2. Create one Task per coherent change, not per line of code.
3. Each Task targets a bounded feature + needed tests/docs.
4. Add explicit dependency ID and automated verification.
5. Prioritize validation loop before community/backend.
6. Maintain `tasks/INDEX.md`; don't dump full plans in AGENTS.md.
