# Release checklist
1. Confirm real device tests and supported SDK versions.
2. Review permissions, storage, backup and privacy disclosures.
3. Run all tests, release build and check binary signing.
4. Check license and dependency vulnerability advisories.
5. No launch or store publishing without owner's approval.
6. Summarize blockers in a release document.
