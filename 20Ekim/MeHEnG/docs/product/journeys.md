# User journeys
## First launch
1. A local workspace opens, no account gate.
2. Explain private storage and optional future community.
3. Create a venture: title, problem, target customer.
4. Open venture detail and create first hypothesis.
5. Plan an experiment and record a real observation.
6. Inspect supportive and contradictory evidence separately.

## Decision loop (future task)
1. Hypothesis is a falsifiable claim.
2. Experiment specifies method, target, success criterion.
3. Evidence records observation and source, not fabricated verdict.
4. Founder records continue / change / stop with rationale.
5. Decision links to referenced evidence IDs.

## Community opt-in (future)
Explicit public projection of a venture with per-field preview.
Public metadata may be withdrawn subject to platform retention policy.
