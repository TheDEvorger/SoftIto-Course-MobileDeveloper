# Privacy by default
Local SQLite currently unencrypted. Never claim otherwise.
- User's private venture notes stay on device in seed.
- No external accounts, analytics, cloud API, network posting in seed.
- Do not use real private client/customer records in early prototypes.
- Explicit per-field opt-in sharing before Network publication.
- Public view must derive from a separate approved projection.
- Identity, membership and authorization must be enforced server-side.
- Future: abuse reporting, moderation, rate limits, encrypted backup.
- Every destructive migration needs rollback/backup testing.
