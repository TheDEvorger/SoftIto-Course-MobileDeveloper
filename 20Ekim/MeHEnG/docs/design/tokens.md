# MeHEnG design tokens
Identity spelling: **MeHEnG**; platform package id: `meheng`.

## Palette
- Primary Forest `#193E38`: key actions, dark surfaces.
- Background Canvas `#F5F2EB`: warm clean paper.
- Accent Copper `#D57C52`: focus moments, not every card.
- Secondary Sage `#9EB8A9`: subtle states.
- Ink `#263331`: body text.
- High-contrast/on-primary `#FFFFFF`.

## Layout
- 4/8/12/16/24/32 px spacing scale; corner radii 10/16/24.
- <700 width: mobile bottom navigation and single column.
- >=700: navigation rail and flexible content.
- Content max width about 1120 px; cards min 240 px.
- Respect text scale and system reduced-motion preferences.

## States
Use semantics, icons and text in addition to color for statuses.
Contradictory evidence should never be hidden by aggregate percentages.
